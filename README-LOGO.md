## Para actualizar con logo real:
1. Descargar logo desde Google Drive
2. Guardar como `public/logo-original.png`
3. Ejecutar `npm run generate-icons` para crear múltiples tamaños
4. Actualizar `manifest.json` con nuevos iconos
5. Subir cambios y desplegar

## Tamaños de icono requeridos:
- 72x72, 96x96, 128x128, 144x144, 152x152
- 192x192, 384x384, 512x512 px
